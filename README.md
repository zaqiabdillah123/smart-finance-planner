## Menjalankan aplikasi secara lokal

1. Pastikan Node.js versi 18 atau lebih baru sudah terpasang.
2. Buka terminal di folder aplikasi.
3. Jalankan:

```powershell
node server.js
```

4. Buka `http://127.0.0.1:5500` di browser.

Data yang dikirim melalui form disimpan secara lokal di `data/history.json`.

Jika port `5500` sedang digunakan Live Server, jalankan port lain:

```powershell
node server.js 5510
```

Lalu buka `http://127.0.0.1:5510`.
